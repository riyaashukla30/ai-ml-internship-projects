# Autonomous Lunar Landing using PPO

A reinforcement learning project that trains an agent to land a spacecraft safely using Proximal Policy Optimization (PPO).

## Features
- Autonomous landing using RL  
- Trained with PPO algorithm  
- Learns thrust control and stability  
- Simulated environment (LunarLander)  

## Tech Stack
Python, Gymnasium, Stable-Baselines3, NumPy  

## How it Works
- Agent interacts with environment  
- Learns from rewards and penalties  
- Optimizes landing using PPO  
- Improves performance over episodes  

## Run
pip install -r requirements.txt  
python train.py  
python test.py
